# Project Shelf

The site is plain HTML, CSS and JavaScript. Open index.html in a browser to preview it. GitHub Pages serves the root of the main branch.

- Edit the About section in index.html when the bio is ready.
- Update the project index in site.js. Keep private project source in its own repository.
- Screen recordings and their posters are in assets. Scout uses synthetic test data. The TV videos show browser previews. Recordings are silent and the page describes what each one shows.
- Bump VERSION, the generator meta tag in index.html and legal.html, and VERSION in site.js before every deployment. The live version shows as `data-version` on the `<html>` element.
- Terms, privacy and the app download notice live in legal.html. Update its last-updated date whenever the text changes.
